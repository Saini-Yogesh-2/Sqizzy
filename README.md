# SQIZZY — Peanut Butter. Rethought.

> **Shake. Squeeze. Drizzle.** The modern, all-natural squeeze peanut butter brand engineered for zero stirring, zero oily mess, and effortless drizzling.

---

## 🥜 Quick Start

```bash
# 1. Install all dependencies across monorepo
npm run install:all

# 2. Start fullstack application (Backend on :5000, Frontend on :3000)
npm run dev

# 3. Build for production
npm run build
```

---

## 🚀 Key Features

- **Interactive Brand Experience:** 3D animated squeeze bottle simulation, "Goodbye Jar" comparison, and rich recipe pairings.
- **Pre-Launch Interest Engine:** Full telemetry capturing CTA click-through rates, product demand by flavor, and VIP waitlist registrations.
- **Private Admin SaaS Analytics:** Access via `/admin` (credentials in `.env.example`). Features conversion funnel, traffic timelines, product interest percentages, device & geo breakdowns, feedback reviews, and CSV exports.
- **Privacy-Conscious First-Party Tracking:** UUID visitor IDs, 30-minute session management, non-blocking `navigator.sendBeacon` dispatch, and zero third-party cookie dependencies.
- **Vercel & Mongo Ready:** Seamless monorepo deployment with dual-mode storage fallback for zero downtime.
